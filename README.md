# Roast the Smart Fridge: One Line, Best Laugh Wins

A one-line roast of a smart fridge that cost $3,000 and still can't do the one thing a free pizza magnet does.

> My $3,000 smart fridge's best feature is a free pizza magnet: it has held the same shopping list since 2019 and never once asked me to update anything.

## Run

```sh
node main.ts
```

This writes the line above to `/output/entry.txt` (151 characters, no trailing newline, UTF-8).
